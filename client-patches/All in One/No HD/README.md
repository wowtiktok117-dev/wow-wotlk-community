## 🎯 ¿Por qué lo recomendamos?

Este parche incorpora mejoras visuales para distintas mecánicas de **World of Warcraft: Wrath of the Lich King 3.3.5a** utilizando los recursos del **cliente estándar (no HD)**.

Está diseñado para funcionar sin configuraciones adicionales y es la opción recomendada para todos los jugadores que utilizan el cliente clásico de Wrath of the Lich King.

En **Wowtiktok WotLK Community**, este parche está **recomendado para todos los jugadores que utilicen el cliente estándar (no HD)**.

## 📦 Instalación

1. Cierra **World of Warcraft**.

2. Copia el archivo del parche dentro de la carpeta y renombra el archivo a "patch-y.mpq":

```text
World of Warcraft/
└── Data/
```

3. Inicia el juego.

> **Recomendación de Wowtiktok WotLK Community**
>
> Este parche ha sido diseñado específicamente para el **cliente estándar (no HD)** y **no requiere ninguna configuración adicional**. Basta con copiar el archivo en la carpeta **Data** para comenzar a disfrutar de las mejoras visuales.
>
> **No se recomienda instalar este parche sobre el cliente HD**, ya que algunas mejoras visuales están adaptadas específicamente para cada versión del cliente.
